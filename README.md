One dad joke, for the make.fun Dad Joke Showdown.

> I named my dog Five Miles so I can tell people I walk Five Miles every day.

`main.py` writes the joke as UTF-8 text to `/output/entry.txt` (75 characters, one line).

## Run

```sh
python3 main.py
```
